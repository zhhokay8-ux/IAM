# 23 日志与审计

## 请求 Trace

`TraceIdFilter`：入站 `X-Request-Id`，否则生成；MDC/TraceId；响应回写同头。内部名 `trace_id`（`TraceId`）。

## 禁止打印

`SensitiveDataMasker` 匹配 access_token、refresh_token、id_token、client_secret、authorization_code、logout_token、code_verifier、Bearer。`CreateClientRequest.toString` 将 secret 打成 `***`。`TokenLoggingFilter` debug 只打脱敏 query。

不要在业务 log 里打 JWT 全文。

## Audit（`iam_audit_log`）

`IamAuditService` 字段：trace_id、event、subject/client/resource、result、failure_reason、detail、created_at。  
事件：LOGIN_SUCCESS/FAILURE、TOKEN_ISSUED、TOKEN_EXCHANGE（detail 含 original_sub、calling_client、target_resource、scope、jti）、TOKEN_REVOKED、LOGOUT、EMBED_*、MIGRATION_*、CLIENT_CREATED/UPDATED。  
**【部分实现】** `POLICY_CHANGED` 枚举有，无写入点。source_ip / user_agent 列存在，Service **未填**。

网关 `AuditGatewayFilter` 打 INFO 日志，不写 DB。
