# 05 环境配置

来源：`iam-authorization-server/.../application.yml`、`IamRedisProperties`、`IamSsoProperties`、`CorsProperties`、`IamProperties`（SDK）、`IamGatewayProperties`、`MigrationProperties`、`@Value`。

| 配置项 | 含义 | 必填 | 默认 | 示例 |
|---|---|---|---|---|
| `spring.datasource.url` | JDBC | 是 | `jdbc:oracle:thin:@//localhost:1521/XEPDB1` | 可用 `DB_URL` |
| `spring.datasource.username` | DB 用户 | 是 | `iam` | `DB_USERNAME` |
| `spring.datasource.password` | DB 密码 | **是** | 无 | `DB_PASSWORD` |
| `spring.data.redis.host/port/password` | Redis | 是 | localhost:6379，密码默认可空字符串 | `REDIS_*` |
| `server.port` | HTTP | 否 | 8080 | |
| `iam.enabled` | 总开关（迁移模块读取） | 否 | true | false 则关 IAM 登录 |
| `iam.issuer` | JWT `iss`、Discovery issuer | 是 | `http://localhost:8080` | `IAM_ISSUER` 生产必须 https |
| `iam.jwt.algorithm` | 文档配置 | 否 | RS256 | 签发代码固定 RS256 |
| `iam.jwt.rsa-key-size` | 生成 RSA | 否 | 2048 | |
| `iam.jwt.access-token-ttl` | yml 有；**实际 TTL 以 Client.accessTokenTtl 秒为准** | 否 | 10m | |
| `iam.admin.access-token` | 用户 Admin API | 否 | 空=禁用 `/api/users` | `IAM_ADMIN_TOKEN` |
| `iam.sso.cookie-name` | SSO Cookie | 否 | `IAM_SSO_SESSION` | |
| `iam.sso.cookie-secure` | Secure | 否 | true | 本地 HTTP 用 `IAM_SSO_COOKIE_SECURE=false` |
| `iam.sso.cookie-same-site` | SameSite | 否 | Lax | |
| `iam.sso.cookie-path` | Path | 否 | `/` | |
| `iam.cors.allowed-origins` | CORS / CSRF Origin 白名单 | 是（生产） | portal、system1、localhost:8080 | 禁止 `*` |
| `iam.cors.embed-parent-origins` | 嵌入页 CSP frame-ancestors | 否 | portal | |
| `iam.cors.allow-credentials` | CORS credentials | 否 | true | 不能与 `*` 同时 |
| `iam.jwks.cache-ttl` | SDK/网关缓存 | 否 | 1h | |
| `iam.jwks.refresh` | 后台刷新 | 否 | 10m | 失败保留旧缓存 `IamJwksClient.refreshQuietly` |
| `iam.redis.authorization-code-ttl` | 授权码 | 否 | 60s | |
| `iam.redis.embed-code-ttl` | Embed | 否 | 30s | |
| `iam.redis.oauth-state-ttl` / `pkce-state-ttl` / `nonce-ttl` | OIDC 状态 | 否 | 5m | |
| `iam.redis.session-ttl` | SSO Session | 否 | 8h | |
| `iam.redis.migration-ticket-ttl` | 与 `iam.migration.ticket-ttl` 并列 | 否 | 45s | 业务 TTL 以 MigrationProperties 夹紧 30–60s |
| `iam.redis.refresh-token-status-ttl` | Redis 刷新状态 | 否 | 30d | |
| `iam.redis.revoked-jti-ttl` | jti 黑名单默认 | 否 | 15m | revoke 时按 Token 剩余寿命 |
| `iam.redis.rate-limit-ttl` | Redis 限流键 | 否 | 1m | 网关未用 Redis |
| `iam.migration.mode` | `legacy` / `iam` / `dual` | 否 | dual | |
| `iam.migration.ticket-ttl` | Ticket | 否 | 45s | |
| `iam.resource-server.audience` | **业务系统** SDK 期望 aud | 业务必填 | 无 | `system-n-api` |
| `iam.resource-server.enabled` | 是否装 JWT Filter | 否 | true | |
| `iam.resource-server.permit-all` | 匿名路径 | 否 | [] | `/public/**` |
| `iam.token.clock-skew` | SDK 时钟偏移 | 否 | 30s | |
| `iam.gateway.*` | 仅网关进程 | 否 | issuer、rate-limit 100/1m | |

Logging：无独立 logback 定制文件。Audit 见 [23](23-日志审计.md)。
