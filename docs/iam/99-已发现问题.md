# 99 已发现问题（仅记录，未改业务代码）

1. **SSO 登录无密码**（`SsoLoginRequest` / `SsoAuthenticationService`）。任何知道 username+tenant 的人可建 IAM Session。生产不可直接暴露。
2. **签名私钥仅在 JVM 内存**（`LocalSigningKeySecretStore`）。重启丢钥；多节点签发不一致；与表注释“KMS/HSM”不符。
3. **`iam-admin` 空**，Client/Resource/Scope/Policy 无 REST。
4. **Discovery `userinfo_endpoint` 无实现**。
5. **授权服务器无 `/health` / Actuator**。
6. **SDK 默认关闭 jti 吊销检查**，`/oauth2/revoke` 对已发出的 AT 在业务侧默认不生效。
7. **嵌入 CSP 仅当 URI 包含 `/embed` 或 `iam-embed.js`**，子应用业务路径可能仍被 `X-Frame-Options: DENY`。
8. **网关无限流共享、无反向代理路由**。
9. **审计 `source_ip`/`user_agent` 未写入**；`POLICY_CHANGED` 未打点。
10. **`POST /sso/login` 无密码也意味着无暴力破解防护。**
11. Refresh `session_id` 列类型 UUID 与 Redis sid 字符串可能不一致，需对照写入代码。
12. `iam.jwt.access-token-ttl` 易误导，真实 TTL 在 Client 行。
