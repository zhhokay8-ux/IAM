# 02 项目目录结构

以仓库根 `ssoProject` 为准（省略 `target/`、测试资源里的 `.gitkeep`）。

```
ssoProject/
├── pom.xml                          # 父 POM，15 个 module
├── Dockerfile                       # 只打包 authorization-server fat jar
├── docker-compose.yml               # oracle + redis + iam
├── docs/                            # 既有架构摘录 + 本说明书 docs/iam/
├── performance/                     # JMeter .jmx 模板
├── iam-common/                      # 错误码、Filter、TraceId
├── iam-core/                        # Redis 基础设施
├── iam-token/                       # JWT 签发、JWKS、Refresh、Redis code
├── iam-audit/                       # 审计实体与 IamAuditService
├── iam-client-registry/             # Client/Resource/Scope/Permission 服务（无 Controller）
├── iam-policy/                      # 策略评估、Token Exchange 策略
├── iam-user/                        # 用户、映射、/api/users
├── iam-session/                     # SSO Session Redis
├── iam-embed/                       # Embed Code / Policy
├── iam-migration/                   # 迁移 Ticket
├── iam-admin/                       # 【空模块】仅 package-info
├── iam-authorization-server/        # 可运行的 IAM HTTP 服务
│   ├── src/main/java/.../oauth|sso|oidc|embed|security
│   ├── src/main/resources/application.yml
│   ├── src/main/resources/db/migration/V1__…V15__
│   └── src/main/resources/static/iam-embed.js
├── iam-resource-server/             # JwtTokenValidator 等（给 SDK 用）
├── iam-sdk-spring-boot/             # Spring Boot Starter
├── iam-gateway/                     # 网关过滤器进程
└── iam-test/                        # 几乎空，仅 package-info
```

不存在：`k8s/`、`helm/`、`frontend/`、`iam-web-sdk/`、`openapi.yaml`。
