# 10 业务系统集成

以 SystemN / order-system 为例，从零接入。

## 最小接入

1. 注册 Resource（audience=`system-order-api`）+ Scope + Client + Permission（`AUTHORIZATION_CODE` 和需要的 grant）。
2. CORS：把前端 Origin 加入 IAM `iam.cors.allowed-origins`（若浏览器直打 IAM）。业务 API 自己的 CORS 另配。
3. 后端加 `iam-sdk-spring-boot`，配置 issuer + audience，见 [11](11-Java后端集成.md)。
4. 前端走 BFF 或携带 IAM Access Token 调业务 API（推荐 BFF 转发 Authorization）。
5. Logout：登记 `LOGOUT_CALLBACK`，实现 `POST /oidc/backchannel-logout` 收 `logout_token`（`BackChannelLogoutServiceImpl` 会向该 URI POST）。

不需要每个请求打 IAM introspect。SDK 本地验 JWT。高风险接口可自行构造 `JtiValidator(true, store)`。

## 配置清单

| 项 | 放哪 |
|---|---|
| issuer | 业务 `iam.issuer` = IAM `iam.issuer` |
| audience | `iam.resource-server.audience` = 资源表 audience |
| JWKS | SDK 自动 `{issuer}/.well-known/jwks.json`，缓存 1h，刷新 10m |
| redirect | Client 表精确 URI |
| Token Exchange | 另授 `TOKEN_EXCHANGE` permission，见 [15](15-Token-Exchange.md) |
| iframe | embed policy 行 + [17](17-iframe集成.md) |
