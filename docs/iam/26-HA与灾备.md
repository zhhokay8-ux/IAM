# 26 HA 与灾备

证据：`IamHighAvailabilityTest`、`JtiValidator`、`JwksCache`、`LocalSigningKeySecretStore`。

| 故障 | 发生什么 |
|---|---|
| 单个 Auth 节点 down | 其他节点若共享 Redis **且共享签名材料** 可继续登录。当前内存钥则其他节点可能没有该 kid。 |
| IAM 全部 down | **已签发、未过期的 Access Token** 业务 API 仍可访问（SDK 本地验签 + 缓存 JWKS）。新登录、换码、refresh、exchange、embed、migration 全部失败。 |
| Redis down | SSO/code/ticket 失败。可选 jti 检查关闭时普通 JWT API 可用。 |
| DB down | IAM 无法校验 Client/用户/RT；SDK 不连 IAM DB。 |
| JWKS 端点 down | 刷新失败保留缓存；无缓存则无法验新 kid。 |
| Gateway down | 直连业务则仍可用；若流量必须经网关则全断。网关限流不跨节点。 |

高风险 API 应 `JtiValidator(true, redisStore)`：Redis 故障 Fail Closed（IAM-5031），避免吊销失效后放行。
