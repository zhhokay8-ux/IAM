# 03 模块说明

依赖方向（父 POM + 各模块 pom）：`authorization-server` 聚合几乎所有业务模块。`iam-sdk-spring-boot` 依赖 `iam-common` + `iam-resource-server`。`iam-client-registry` 依赖 `iam-core` + `iam-audit`。

---

## iam-common

**职责**：统一错误、TraceId、安全 Filter、脱敏。  
**为何存在**：所有 HTTP 入口共享同一套错误 JSON 与 CSRF/CORS/Header。  
**核心类**：`IamErrorCode` / `IamException` / `GlobalExceptionHandler` / `ApiErrorResponse`；`TraceId` + `TraceIdFilter`（头 `X-Request-Id`）；`CsrfValidationFilter`（Cookie 会话写操作）；`IamCorsFilter`；`SecurityHeadersFilter`；`TokenLoggingFilter`；`SensitiveDataMasker`；`CsrfTokenService`（Cookie `IAM_CSRF`，头 `X-CSRF-Token`）。  
**何时调用**：授权服务器 `IamWebSecurityConfiguration` 注册 Filter。  
**测试**：`SecurityRegressionTest`、`IamErrorCodeTest`。

## iam-core

**职责**：Redis 连接与 Key 前缀。  
**核心类**：`RedisKeyConstants`、`IamRedisProperties`（`iam.redis.*` TTL）、`IamRedisRepository`、`IamRedisConfiguration`。  
**表**：无。

## iam-token

**职责**：发 Access/ID/Refresh、JWKS、签名、授权码 Redis。  
**核心**：`AccessTokenServiceImpl` 写 JWT claims；`IdTokenServiceImpl` 写 nonce；`JwtSigner`；`JwksController` `GET /.well-known/jwks.json`；`SigningKeyServiceImpl` 创建 RS256 钥；`LocalSigningKeySecretStore` 存私钥；`RefreshTokenServiceImpl` / `RefreshTokenFamilyServiceImpl` 轮换与复用打击；Redis：`AuthorizationCodeRepository`、`OAuthStateRepository`、`PkceStateRepository`、`NonceRepository`、`RevokedJtiRepository`、`RefreshTokenStatusRepository`。  
**谁调用**：Token Grant Handler、Introspect、Revoke、业务侧 JWKS。  
**表**：`iam_refresh_token`、`iam_signing_key`。

## iam-audit

**职责**：落库审计。  
**核心**：`AuditEvent` 枚举、`IamAuditService.record`、`IamAuditLogEntity`。  
**何时**：登录、发 Token、Exchange、Revoke、Logout、Embed、Migration、Client 创建/更新。  
**表**：`iam_audit_log`（含 V15 `detail`）。

## iam-client-registry

**职责**：注册 Client / Resource / Scope / Permission。  
**核心 Service**：`IamClientServiceImpl.create/update`（secret 只存 SHA-256，`HashUtils`）、`IamResourceServiceImpl`、`IamScopeServiceImpl`、`IamPermissionServiceImpl`。  
**校验**：`IamRedirectUriValidator` 精确匹配、禁止通配；`IamClientValidator.rejectDynamicRegistration`。  
**HTTP**：【设计存在但代码未实现】无 Controller。  
**表**：`iam_client`、`iam_client_redirect_uri`、`iam_resource_server`、`iam_scope`、`iam_client_resource_permission`。

## iam-policy

**职责**：redirect / origin / scope / audience / token-exchange 是否允许。  
**核心**：`IamPolicyEvaluator`、`TokenExchangePolicyService`。  
**RateLimitRepository**：Redis `rate:limit:`，给策略模块用；网关自己用内存计数，不走这个 Repository。

## iam-user

**职责**：统一用户与外部身份映射。  
**核心**：`IamUserService`、`IamIdentityMappingService`、`UserSubjectGenerator`、`UserContextFactory`（发 Token 时组身份）。  
**Controller**：`IamUserController` `/api/users/**`，拦截器 `IamAdminAccessInterceptor`（头 `X-IAM-Admin-Token` = `iam.admin.access-token`；空则 403 禁用）。  
**表**：`iam_user`、`iam_user_identity_mapping`。

## iam-session

**职责**：SSO Session JSON 存 Redis。  
**核心**：`IamSessionServiceImpl` TTL 默认 8h（`iam.redis.session-ttl`）。  
**调用**：登录、authorize、logout、migration redeem、embed 校验 session。

## iam-embed

**职责**：一次性 embed code + 策略。  
**核心**：`EmbedCodeServiceImpl.issue/exchange`、`EmbedPolicyServiceImpl.requireActive`、`OriginValidator`。  
**TTL**：`iam.redis.embed-code-ttl` 默认 30s。  
**表**：`iam_embed_policy`。Policy 无 HTTP 写入 API。

## iam-migration

**职责**：Legacy → IAM 一次性 ticket。  
**核心**：`MigrationLoginController`、`MigrationTicketServiceImpl`、`MigrationProperties`（mode `legacy|iam|dual`，ticket TTL 夹在 30–60s）。  
**API**：`POST /api/migration/ticket`、`GET /migration/login?ticket=`。禁止 query 带 session/JWT。

## iam-admin

**【设计存在但代码未实现】** 仅 `package-info.java`。

## iam-authorization-server

**职责**：对外 HTTP。  
**入口**：`IamAuthorizationServerApplication`。  
**Controller**：Authorize、Token、TokenExchange、Introspect、Revoke、SSO、Logout、Embed、OIDC Discovery；加上扫描进来的 User、JWKS、Migration。  
**配置**：`IamWebSecurityConfiguration` 挂安全 Filter。

## iam-resource-server

**职责**：纯校验库。  
**核心**：`JwtTokenValidator`、`IssuerValidator`、`AudienceValidator`、`ScopeValidator`、`RoleValidator`、`JtiValidator`。高风险路径把 `JtiValidator` 设 `enabled=true`，存储异常 → `INTROSPECTION_UNAVAILABLE` Fail Closed。

## iam-sdk-spring-boot

**职责**：业务系统 Starter。  
**自动配置**：`IamAutoConfiguration`（`iam.resource-server.enabled` 默认 true）、`EnableScheduling` + `JwksRefreshScheduler`（`${iam.jwks.refresh:10m}`）。  
**核心**：`IamJwtAuthenticationFilter`、`IamJwksClient`/`JwksCache`、`IamTokenClient.clientCredentials`、`IamUserContextHolder`、`@RequireScope`/`@RequireRole` Aspect。  
**测试**：`SdkStarterE2ETest`、`IamHighAvailabilityTest`。

## iam-gateway

**职责**：演示网关 Filter。  
**核心**：`RequestIdFilter`、`CorsGatewayFilter`、`RateLimitFilter`（**进程内 Map**）、`JwtGatewayFilter`、`AuditGatewayFilter`。  
**限制**：排除 Redis/DB；无路由；限流不跨节点。

## iam-test

空占位 `package-info`。
