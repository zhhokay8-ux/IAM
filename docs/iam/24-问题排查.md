# 24 问题排查

每个问题：现象 → 原因 → 检查 → 处理。

1. **redirect_uri mismatch**  
   302 失败或 IAM-4046。登记 URI 必须逐字符相同。检查 Client redirect 行与请求。

2. **invalid_client (IAM-4006)**  
   secret 错、client 不存在。用 Basic 或 form；hash 是 SHA-256。

3. **invalid_grant (IAM-4013)**  
   code 用过/过期/redirect 不一致。60s 内一次兑换。

4. **PKCE failed**  
   method 不是 S256，或 verifier 与 challenge 不配。

5. **invalid_scope**  
   permission 未绑该 scope，或 scope 停用。

6. **audience mismatch (IAM-4018)**  
   业务 `iam.resource-server.audience` ≠ Token aud ≠ 资源表 audience。

7. **issuer mismatch**  
   业务 issuer 与发 Token 的 `iam.issuer` 不一致（含尾斜杠规范化）。

8. **JWT signature invalid**  
   钥已换且 JWKS 缓存旧；或进程重启内存私钥丢了（IAM-5030）。

9. **unknown kid**  
   Token kid 不在 JWKS。重启 IAM 后旧 Token 常这样。

10. **JWKS 获取失败**  
    业务仍可用 stale cache；无缓存则 SIGNING_KEY_NOT_FOUND。

11. **Token expired**  
    Client TTL 到了。对表 `access_token_ttl`。

12. **401**  
    缺 Bearer、Cookie 无、用户停用。看 `code` 字段。

13. **403**  
    CSRF、permission、scope/role、client 无 CC/TE 授权。

14. **SSO 不生效**  
    Cookie 域不是 IAM；Secure=true 却用 HTTP；SameSite 跨站。

15. **Cookie 不存在**  
    `credentials: 'include'`、CORS allow-credentials、Origin 在白名单。

16. **iframe 无法加载**  
    普通页 CSP `frame-ancestors 'none'`。嵌入路径需含 `/embed` 或 `iam-embed.js` 才会换 CSP（`SecurityHeadersFilter.isEmbed`）。子应用页面若路径不含 embed，仍可能 DENY。

17. **iframe 被 CSP 阻止**  
    `embed-parent-origins` 未含 Portal Origin。

18. **postMessage 不工作**  
    用了 `*`（脚本抛错）或 origin/nonce/aud/exp 不匹配。

19. **CORS 错误**  
    Origin 不在 `iam.cors.allowed-origins`。

20. **CSRF 错误**  
    POST 带了 SSO Cookie 但没有 `X-CSRF-Token` 或 Origin。OAuth `/oauth2/*` 豁免。

21. **Token Exchange 失败**  
    缺 TOKEN_EXCHANGE permission；audience 未登记；subject 过期。

22. **Refresh reuse**  
    旧 refresh 再用不成功且家族全废。前端应只存最新。

23. **Migration ticket expired**  
    默认 45s，只一次。

24. **Mapping missing**  
    无 `iam_user_identity_mapping`。

25. **Redis unavailable**  
    登录/code 失败；本地 JWT 业务仍可。

26. **Database unavailable**  
    IAM 起不来（Flyway/JPA）；已签 JWT 仍可被 SDK 验。

27. **Key rotation 后失败**  
    旧 kid 应仍在 JWKS 直至退役；内存 store 无持久化则全挂。

28. **Logout 后仍登录**  
    只做了 local；业务自己 Session 未接 back-channel。

29. **Client 没权限**  
    查 `iam_client_resource_permission` grant_type。

30. **Scope 不生效**  
    Token 的 scope 字符串未含所需项；`@RequireScope` 精确匹配 `ScopeValidator`。

31. **Admin API 403**  
    未设 `IAM_ADMIN_TOKEN`。

32. **登录无密码仍成功**  
    当前实现如此，不要当安全登录用。见 99。
