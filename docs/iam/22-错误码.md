# 22 错误码

来源：`IamErrorCode`。排查结合对应校验类。

| Error Code | HTTP | 含义 | 排查 |
|---|---|---|---|
| IAM-4000 | 400 | Invalid argument | 缺字段 |
| IAM-4001 | 400 | Invalid redirect URI | 语法/通配 |
| IAM-4002 | 400 | Invalid client type | CONFIDENTIAL/PUBLIC |
| IAM-4003 | 400 | Invalid grant type | grant 枚举 |
| IAM-4004 | 400 | Invalid origin | CORS/CSRF Origin |
| IAM-4005 | 400 | Invalid JWT | 解析失败 |
| IAM-4006 | 400 | invalid_client | 认证失败 |
| IAM-4007 | 400 | Invalid PKCE | 非 S256 / verifier |
| IAM-4008 | 400 | unsupported_response_type | 只用 code |
| IAM-4010 | 401 | Unauthorized | 缺 Bearer |
| IAM-4011 | 401 | Client disabled | status |
| IAM-4012 | 401 | Invalid JWT signature | 钥/算法 |
| IAM-4013 | 400 | invalid_grant | code/refresh |
| IAM-4014 | 400 | Authorization code expired | 60s |
| IAM-4015 | 401 | JWT expired | exp |
| IAM-4016 | 401 | nbf | 时钟 |
| IAM-4017 | 401 | issuer | 与 iam.issuer 不一致 |
| IAM-4018 | 401 | audience | 业务 audience 配错 |
| IAM-4019 | 401 | Token revoked | jti 黑名单 |
| IAM-4030 | 403 | Forbidden | 通用 |
| IAM-4031 | 403 | Permission denied | 无 permission 行 |
| IAM-4032 | 403 | Token exchange not allowed | 缺 TOKEN_EXCHANGE |
| IAM-4033 | 403 | CC not allowed | 缺 CLIENT_CREDENTIALS |
| IAM-4034 | 403 | Dynamic registration forbidden | 不要调 dynamicRegister |
| IAM-4035 | 403 | Scope inactive | |
| IAM-4036 | 403 | User inactive | |
| IAM-4037 | 403 | Signing key retired | 轮换后旧钥 |
| IAM-4038 | 403 | Insufficient scope | @RequireScope |
| IAM-4039 | 403 | Insufficient role | @RequireRole |
| IAM-4040–4049 | 404 | 资源/client/scope/aud/mapping/key 不存在 | |
| IAM-4046 | 404 | Redirect URI mismatch | 差一个字符也会失败 |
| IAM-4050–4053 | 401 | SSO session/cookie | Cookie 域、过期、篡改 |
| IAM-4054–4055 | 401/403 | actor_token | |
| IAM-4060–4067 | 400/401/403 | Embed | origin/path/replay |
| IAM-4068 | 400 | Invalid logout token | |
| IAM-4070–4078 | 各种 | Migration | ticket/mapping/URL 泄密 |
| IAM-4079 | 403 | CSRF | 头与 Cookie、Origin |
| IAM-4080 | 400 | access_token in URL | TokenLoggingFilter |
| IAM-4090–4097 | 409 | 唯一约束冲突 | |
| IAM-4290 | 429 | Rate limited | 网关内存限流 |
| IAM-5000 | 500 | Internal | 看日志 traceId |
| IAM-5030 | 503 | No active signing key | 内存钥丢失 |
| IAM-5031 | 503 | Introspection unavailable | 高风险 Fail Closed |

Filter 直接写 JSON 时可能没有 traceId 字段（CSRF/TokenLogging）。
