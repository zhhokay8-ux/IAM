# 12 Web 前端集成指南

**【当前项目不支持】** `iam-web-sdk` npm 包。仅有 `iam-authorization-server/src/main/resources/static/iam-embed.js`（运行时 `/iam-embed.js`）。

## Vue / React / 普通 HTML

模式相同：**浏览器不要保存 refresh_token / client_secret**。Access Token 若必须在 SPA，用内存变量，勿 localStorage。推荐 BFF Cookie Session。

| Token | 浏览器？ |
|---|---|
| `IAM_SSO_SESSION` | 是，HttpOnly，JS 读不到 |
| `IAM_CSRF` | 是，非 HttpOnly，JS 读后放到 `X-CSRF-Token` |
| Access Token | 仅内存或 BFF |
| Refresh Token | **禁止** |
| ID Token | 可选内存，注意泄露 |

Cookie：SSO `Secure` 默认 true、`SameSite=Lax`、`Path=/`。CSRF Cookie `SameSite=Lax`，Secure 随 `request.isSecure()`。

## 登录 / 退出 / 401 / 403

登录：[09](09-Portal集成.md)。退出：[18](18-Logout.md)。  
业务 401：SDK 无 Bearer 或 JWT 无效。403：scope/role 不足或 CSRF/Origin。  
Session 过期：`GET /sso/session` 返回 `SESSION_EXPIRED`，需重新 `/sso/login` + authorize。

## iframe

用 `IamEmbed.postToChild(iframe, message, targetOrigin)`。`targetOrigin` 含 `*` 会抛错。子页 `acceptParentMessage` 校验 `event.origin`、nonce、aud、exp。

## 刷新 Token

SPA 调 BFF `grant_type=refresh_token`。复用检测：旧 refresh 再用会吊销整个 family（`TokenControllerTest.refreshReuseRevokesFamily`）。
