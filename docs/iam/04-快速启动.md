# 04 快速启动

依据：`application.yml`、`docker-compose.yml`、`Dockerfile`、`IamAuthorizationServerApplication`。

## 版本

- JDK：编译 17；建议运行 **21**（Dockerfile `eclipse-temurin:21-jre`；测试环境亦曾使用 21）。
- Maven 3.x（仓库未钉死 Maven 发行版）。
- Oracle 21 XE（Compose 镜像 `gvenzl/oracle-xe:21-slim-faststart`，服务名 `XEPDB1`）。
- Redis 7（Compose 镜像，`--requirepass`）。

## 本地启动（不用 Compose 构建镜像时）

1. 启动 Oracle，可插拔库 `XEPDB1`，应用用户 `iam`。
2. 启动 Redis，并设置密码（与 `REDIS_PASSWORD` 一致）。
3. **不要**手工跑 SQL：Flyway `spring.flyway.enabled=true`，位置 `classpath:db/migration`。
4. 环境变量（密码无默认值，必须提供 `DB_PASSWORD`）：

```powershell
$env:DB_URL="jdbc:oracle:thin:@//localhost:1521/XEPDB1"
$env:DB_USERNAME="iam"
$env:DB_PASSWORD="your-db-password"
$env:REDIS_HOST="localhost"
$env:REDIS_PORT="6379"
$env:REDIS_PASSWORD="your-redis-password"
$env:IAM_ISSUER="http://localhost:8080"
$env:IAM_SSO_COOKIE_SECURE="false"
$env:IAM_ADMIN_TOKEN="change-me-admin"
```

5. 启动：

```powershell
mvn -pl iam-authorization-server -am package -DskipTests
java -jar iam-authorization-server/target/iam-authorization-server-0.1.0-SNAPSHOT-exec.jar
```

6. 冒烟（**不是 health**）：

```bash
curl -s http://localhost:8080/.well-known/openid-configuration
curl -s http://localhost:8080/.well-known/jwks.json
```

首次启动 `SigningKeyInitializer` 会生成一把 RS256 钥，元数据进 `iam_signing_key`，私钥进内存 `LocalSigningKeySecretStore`。**重启进程后内存私钥丢失**，旧 Token 的 kid 可能验不了，除非重新签发。见 [99-已发现问题.md](99-已发现问题.md)。

## Docker Compose

```powershell
$env:ORACLE_PASSWORD="..."
$env:REDIS_PASSWORD="..."
mvn -pl iam-authorization-server -am package -DskipTests
docker compose up --build
```

`iam` 服务映射 `8080:8080`。`IAM_SSO_COOKIE_SECURE` 在 Compose 里写死 `"false"` 方便 HTTP。

## 验证不存在的路径

下列路径**不要**用来探活：`/health`、`/actuator/health`、`/swagger-ui`。【设计存在但代码未实现】（网关配置里 permit-all 提到了 `/health`，授权服务器未实现该 Controller）。
