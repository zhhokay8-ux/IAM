# 19 权限模型

```
Client  --permission(grant_type)-->  Resource(audience) --scope--> Business API
                                         ↑
                                    JWT aud + scope
User  --roles(claim)-->  @RequireRole     （角色从用户/Token 来，不是独立角色表）
```

- **IAM 负责**：这个 client 能否用这个 grant 拿到这个 audience+scope 的 Token；JWT 是否由我签发。
- **业务系统负责**：这个 sub 能不能看订单 123；库存、金额、租户隔离。
- **不要**把数据权限列表塞进 JWT（体积、缓存、变更延迟）。

Role：Access Token 可选 `roles` 数组；仓库**没有**独立 `iam_role` 表。用户实体无 roles 列——发 Token 时从 `UserContext` 带出（`UserContextFactory`）。若工厂不填 roles，Token 无该 claim。

Gateway 只做 JWT 存在性/iss 初验，**不**代替 `@RequireScope`。
